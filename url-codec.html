Encoding modes & shortcuts
  • URL component escapes URL separators such as :, /, ?, &, and =. Use it for a single parameter key or value.
  • Full URL preserves URL delimiters. Its decoder also preserves escapes for reserved delimiters; use component mode to decode those.
  • Form component uses + for spaces and %2B for literal plus signs. It transforms a single value, not an entire key/value query string.
  • Query inspection splits on & and the first =, decodes each part, and treats + as a space. Duplicate keys and empty values remain separate.
  • Decoding is one pass. Invalid percent escapes or invalid UTF-8 produce an error rather than silently changing the text.
  • Ctrl/⌘ + Enter encodes; Ctrl/⌘ + Shift + Enter decodes.
